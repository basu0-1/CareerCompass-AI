## 📌 Overview

CareerCompass AI is a **production-ready Full-Stack AI Career Intelligence Platform** designed to help students and professionals improve their career journey using Artificial Intelligence, Machine Learning, and Natural Language Processing.

The platform provides intelligent resume analysis, ATS optimization, skill gap detection, job recommendations, interview preparation, salary prediction, and personalized learning roadmaps through a modern and interactive web interface.

* 📄 AI Resume Analyzer

* 📚 Personalized Learning Roadmap

## ⚡ Getting Started

### Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/CareerCompassAI.git
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
python -m venv venv
```

Activate the virtual environment and install the required dependencies before starting the FastAPI server.
